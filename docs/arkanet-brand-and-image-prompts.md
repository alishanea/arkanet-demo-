## 2. Arkanet Visual Style Guide for Image Generation

To maintain strict visual consistency with the website, all generated images should follow these art-direction rules:

| Attribute | Guidelines |
|---|---|
| **Color Palette** | Deep Navy (`#202B61`), Cobalt Blue (`#3B82F6`), Crisp White (`#FFFFFF`), Slate Gray (`#F4F6FB`), subtle Crimson accent (`#D61F28`). |
| **Aesthetic** | Architectural, editorial, minimalist, high-end enterprise software studio (reminiscent of Stripe, Apple Enterprise, Vercel). |
| **Lighting** | Soft volumetric daylight, cool diffuse glass reflections, clean ambient luminescence. Avoid dark harsh neon or saturated rainbow lighting. |
| **Aspect Ratios** | `16:9` for section heroes and desktop banners; `4:3` or `16:10` for feature cards; `1:1` for square showcases. |
| **Composition** | Clean negative space in the center or along the left third to allow readable text overlays and headlines. |
| **Forbidden** | ❌ No cartoonish humanoid robots with glowing blue eyes, ❌ no cheesy stock-photo thumbs-up handshakes, ❌ no cluttered floating generic clip-art icons, ❌ no dark 1980s cyberpunk matrix grids. |
